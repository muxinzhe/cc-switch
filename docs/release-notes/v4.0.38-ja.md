# CC Switch v4.0.38

- **Apple Silicon Mac に SSH で接続できます。** 初回接続時に、デスクトップアプリが接続先に合うエージェントをインストールし、検証します。対応ホストは macOS arm64、Linux x86_64、Linux ARM64 です。
- **単一のエージェントでリモートのセッション、使用量、プロバイダー設定を管理します。** セッションはホストの元のログから読み込み、使用量とプロバイダー設定は `~/.cc-switch-ssh/cc-switch.db` に保存します。
- **Codex 公式ログインの重複表示を修正しました。** SSH データベースの初期作成時に、使用中の ChatGPT 公式ログインと設定を 1 件の `OpenAI Official` に取り込みます。選択中のカスタムエンドポイントや API キー設定は個別のプロバイダーとして取り込めます。

**旧版からのアップグレード時**には、ホストで現在使用中の設定を取り込みます。旧データベースだけに保存されているプロバイダーは個別の取り込みが必要です。元のレコードは `~/.cc-switch-ssh/provider-v1/data/cc-switch.db` に残ります。
