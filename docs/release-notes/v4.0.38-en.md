# CC Switch v4.0.38

- **Connect to Apple Silicon Macs over SSH.** On the first connection, the desktop app installs and verifies the agent for the remote host. Supported hosts include macOS arm64, Linux x86_64 and Linux ARM64.
- **One agent handles remote sessions, usage and provider settings.** Sessions are read from the host’s original logs. Usage and provider settings are stored in `~/.cc-switch-ssh/cc-switch.db`.
- **Fixed duplicate entries for Codex official login.** When the SSH database is first created, the active ChatGPT login and settings are imported into one `OpenAI Official` entry. An active custom endpoint or API key configuration can still be imported as a separate provider.

**When upgrading**, the new agent imports the host’s current native configuration. Providers stored only in the old database need a separate import. Their original records remain in `~/.cc-switch-ssh/provider-v1/data/cc-switch.db`.
