# CC Switch v4.0.38

- **SSH 支持 Apple Silicon Mac。** 首次连接时，桌面端会根据远端平台安装并校验对应的 agent。支持的主机包括 macOS arm64、Linux x86_64 和 Linux ARM64。
- **一个 agent 管理远端会话、用量和供应商配置。** 会话从主机的原始日志读取，用量和供应商配置保存在 `~/.cc-switch-ssh/cc-switch.db`。
- **修复 Codex 官方登录重复显示。** 首次建立 SSH 数据库时，现用的 ChatGPT 官方登录和配置会导入同一条 `OpenAI Official` 记录。已选中的自定义端点和 API Key 配置仍可作为独立供应商导入。

**从旧版升级**时，新 agent 会导入主机当前的原生配置。只保存在旧库中的供应商需要单独导入，原记录仍在 `~/.cc-switch-ssh/provider-v1/data/cc-switch.db`。
