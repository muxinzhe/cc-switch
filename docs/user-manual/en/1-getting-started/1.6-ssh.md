# SSH hosts in the main window

Expand **SSH hosts** in the sidebar and select **Add host**. Pick an alias from your local `~/.ssh/config`, including aliases from `Include` files, or enter `user@host`, a port and an optional identity file. The host configuration is saved in the desktop app data directory. Turn a host off to exclude it from the remote data views.

Verify the SSH host key in a terminal before connecting. The desktop app supports Linux x86_64, Linux ARM64, and Apple Silicon macOS hosts. It uses OpenSSH to install the matching agent as `~/.cc-switch-ssh/agent` and verifies its SHA-256 digest. Later connections reuse or update the same file. The agent accepts commands on a private Unix socket and stores provider configuration, usage, and scan progress in `~/.cc-switch-ssh/cc-switch.db`.

- **Usage** adds a machine filter to the existing overview, charts, and detail tables. Choose all machines, this computer, or one host. The agent calculates usage from the host’s session logs.
- **Sessions** shows the source machine in the existing session list. Filter by machine and open any transcript in the same reader.
- **Providers** has a machine selector for this computer and enabled SSH hosts. Each host opens the same provider list, editor, and action menu.

Choose **Sync from this computer** to copy a saved provider to the selected host. For native application files, select **Configuration files** next to the machine selector. You can edit the file or review a copy of the matching local file before saving. The confirmation shows the destination host and path. Existing native files are backed up under `~/.cc-switch-ssh/config-backups/`.
