# 在主窗口管理 SSH 主机

在左侧栏展开 **SSH 主机** 并点击 **添加服务器**。可以从本机 `~/.ssh/config`（含 `Include`）选择别名，也可以填写 `user@host`、端口和可选的密钥文件。配置保存到 Mac 上的 CC Switch 数据目录。关闭主机开关可以暂停收集该机器的数据，重新打开时会继续连接。

首次连接前，请在终端核对 SSH 主机密钥。桌面端支持 Linux x86_64、Linux ARM64 和使用 Apple Silicon 的 macOS 主机。它通过 OpenSSH 把对应的 agent 安装到 SSH 用户的 `~/.cc-switch-ssh/agent`，并校验 SHA-256。后续连接自动复用或更新同一文件。agent 通过用户私有的 Unix socket 接收命令，将供应商配置、用量和扫描进度保存在 `~/.cc-switch-ssh/cc-switch.db`。

- **用量**在原有的概览、趋势和明细页面加入机器筛选，可以查看全部机器或单独查看本机、某台主机。远端用量来自会话日志，费用为估算。
- **会话**在原有列表中合并各机器并标注来源。agent 读取该主机上的应用原始记录，按机器筛选后即可在同一个阅读器中打开会话。
- **供应商**在页内选择「本机」或已启用的 SSH 主机。选中主机后，页面继续使用原有供应商列表、编辑器和操作菜单，配置操作由该主机上的 CC Switch 后端执行。

在远端供应商页点 **同步本机配置**，选择要同步的供应商并保存。也可以从主机选择器旁的 **配置文件** 直接管理应用原生文件。这个入口支持载入本机同类文件，保存确认会显示主机和目标路径。已有的远端原生文件备份在 `~/.cc-switch-ssh/config-backups/`。
