# 在主窗口管理 SSH 主机

在左侧栏展开 **SSH 主机** 并点击 **添加服务器**。可以从本机 `~/.ssh/config`（含 `Include`）选择别名，也可以填写 `user@host`、端口和可选的密钥文件。配置保存到 Mac 上的 CC Switch 数据目录。关闭主机开关可以暂停收集该机器的数据，重新打开时会继续连接。

首次启用 Linux x86_64 或 ARM64 主机时，Mac 下载并校验静态 CC Switch CLI 后，通过现有 OpenSSH 安装到 SSH 用户的 `~/.cc-switch-ssh/`。先在终端核对主机密钥。再次连接会复用已校验的 CLI。会话和用量扫描的缓存保存在安装目录内。

- **用量**在原有的概览、趋势和明细页面加入机器筛选，可以查看全部机器或单独查看本机、某台主机。远端用量来自会话日志，费用为估算。汇总需要服务器已有的 Python 3。
- **会话**在原有列表中合并各机器并标注来源。按机器筛选后，点选会话即可在同一个阅读器中打开。
- **供应商**在页内选择「本机」或已启用的 SSH 主机。选中主机后，页面继续使用原有供应商列表、编辑器和操作菜单，配置操作由该主机上的 CC Switch 后端执行。首次打开主机的供应商页时，桌面端会安装内置的无界面后端。

在远端供应商页点 **同步本机配置**，选择要同步的供应商并保存。也可以从主机选择器旁的 **配置文件** 直接管理应用原生文件。这个入口支持载入本机同类文件，保存确认会显示主机和目标路径。已有的远端原生文件备份在 `~/.cc-switch-ssh/config-backups/`。
